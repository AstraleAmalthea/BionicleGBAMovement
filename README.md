Bionicle (2003) GBA — Movement Patch

The original game uses an isometric control scheme where pressing a single D-pad direction moves the character diagonally across the screen.

This patch changes the controls so that movement corresponds to the direction pressed.

Press Select to toggle between the original and patched movement controls anywhere, useful for the password entry screen.

The game has an cheat menu you can access with
L L R L Select Start A
shoulder buttons, not the dpad.
